# 📱 오즈샵 (Oz Shop) 실시간 웹 메신저

온라인 샵 운영 및 상품 판매 고객 응대를 위한 1:다(1 Master vs Multi Clients) 실시간 상담 웹 메신저입니다. 별도의 앱 설치 없이 웹 링크만 클릭하면 모바일과 PC에서 즉시 1:1 상담을 진행할 수 있습니다.

## 🚀 빠른 시작 가이드

### 1. 로컬 및 모바일(와이파이) 접속
`run_oz_messenger.bat`을 더블 클릭하여 실행합니다.
- **PC 웹 브라우저**: `http://localhost:8000`
- **모바일 웹 브라우저**: 콘솔에 표시되는 `http://[내PC IP]:8000` (동일 Wi-Fi 연결 시)

### 2. 외부 인터넷 공개 링크 발급 (선택 사항)
스마트폰 LTE/5G 환경이나 외부 고객에게 전송할 수 있는 공용 HTTPS 링크가 필요할 때:
1. `run_oz_messenger.bat`을 실행해 둔 상태에서
2. `run_public_tunnel.bat`을 더블 클릭합니다.
3. 생성된 `https://xxxx.trycloudflare.com` 링크를 복사하여 모바일이나 고객에게 공유합니다.

## 🎨 주요 기능 및 UI 특징

1. **대한민국 표준시(KST, UTC+9) 완벽 적용**
   - 클라우드(Render, AWS 등)나 로컬 PC 어떤 환경에서도 메시지 발송 시각 및 대화 내역 시간이 한국 시간(KST)으로 정확하게 표기됩니다. (`YYYY.MM.DD HH:mm`)
2. **빠른 답변 템플릿 실시간 수정 및 추가 기능**
   - 마스터 콘솔의 **`[⚙️ 문구 수정]`** 버튼을 통해 인사말, 계좌 번호, 배송 안내 규정, 교환/반품 안내 문구를 화면에서 바로 수정하고 저장할 수 있습니다.
   - 새로운 빠른 답변 템플릿 추가 및 필요 없는 템플릿 삭제도 지원합니다.
3. **요구사항 100% 반영된 말풍선 레이아웃**
   - **마스터("오즈샵") 대화**: 왼쪽 노출 (오즈샵 프로필 아바타 + 이름)
   - **일반 고객 대화**: 오른쪽 노출
   - 최신 대화 순으로 아래에 쌓이며 자동 스크롤
4. **미디어 첨부 (스마트폰 최적화)**
   - **사진 전송**: 모바일 기기 접속 시 스마트폰 갤러리 또는 카메라 촬영 연동. 클릭 시 확대 라이트박스 팝업 제공.
   - **파일 첨부**: PDF, 견적서, 각종 문서 파일 전송 및 다운로드.
5. **실시간 양방향 통신 (WebSocket)**
   - 새로고침 없는 실시간 메시지 송수신 및 새 메시지 수신 시 부드러운 차임벨 사운드 알림.

│       ├── index.js         # 메인 페이지 로직
