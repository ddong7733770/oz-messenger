# 📱 오즈 메신저 (Oz Messenger)

온라인 샵 운영 및 상품 판매 고객 응대를 위한 1:다(1 Master vs Multi Clients) 실시간 상담 웹 메신저입니다. 별도의 앱 설치 없이 웹 링크만 클릭하면 모바일과 PC에서 즉시 1:1 상담을 진행할 수 있습니다.

---

## 🚀 빠른 시작 가이드

### 1. 로컬 및 모바일(와이파이) 접속
`run_oz_messenger.bat`을 더블 클릭하여 실행합니다.
- **PC 웹 브라우저**: `http://localhost:8000`
- **모바일 웹 브라우저**: 콘솔에 표시되는 `http://[내PC IP]:8000` (동일 Wi-Fi 연결 시)

### 2. 외부 인터넷 공개 링크 발급 (선택 사항)
스마트폰 LTE/5G 환경이나 외부 고객에게 전송할 수 있는 공용 HTTPS 링크가 필요할 때:
1. `run_oz_messenger.bat`을 실행해 둔 상태에서
2. `run_public_tunnel.bat`을 더블 클릭합니다.
3. 생성된 `https://xxxx.trycloudflare.com` 링크를 복사하여 모바일이나 고객에게 공유합니다.

## 🎨 주요 기능 및 UI 설계

1. **실시간 양방향 통신 (WebSocket)**
   - 메시지 송수신 시 새로고침 없이 즉시 화면에 반영됩니다.
   - 새 메시지 도착 시 기분 좋은 맑은 차임벨(Web Audio) 사운드와 함께 알림이 울립니다.
2. **말풍선 레이아웃 (요구사항 완벽 반영)**
   - **마스터("오즈")의 대화**: 왼쪽 노출 (오즈 프로필 아바타 + 대화명)
   - **일반 고객의 대화**: 오른쪽 노출
   - 메시지 하단에 작게 보낸 일자, 시간, 분 표시 (`YYYY.MM.DD HH:mm`)
   - 최신 대화 순으로 아래에 쌓이며 자동 스크롤
3. **미디어 첨부 (스마트폰 최적화)**
   - **사진 전송**: 모바일 기기 접속 시 갤러리 또는 카메라 촬영으로 즉시 사진 전송 및 대화창 내 썸네일 미리보기/확대 뷰어 제공.
   - **파일 첨부**: 견적서, PDF, 각종 문서 파일 전송 및 원클릭 다운로드.
4. **온라인 샵 상담 특화 기능 (마스터 콘솔)**
   - **좌측 고객 리스트**: 마지막 대화 문구, 시각, 안 읽은 메시지 수(🔴 뱃지), 상담 상태 표시
   - **빠른 답변 템플릿**: 인사, 계좌 안내, 배송 안내, 교환/반품 안내를 버튼 하나로 입력
   - **고객 메모장 (간이 CRM)**: 고객별 주문 번호, 문의 품목, 특이사항을 기록하면 실시간 자동 저장

```
oz_messenger/
├── backend/
│   ├── database.py          # SQLite DB 모델 및 초기화
│   ├── main.py              # FastAPI 서버, WebSocket 통신 및 REST API
│   ├── messenger.db         # 로컬 SQLite 데이터베이스 파일 (자동 생성)
│   └── uploads/             # 업로드된 사진 및 파일 저장소

│   ├── index.html           # 접속 1페이지 (프로필 생성 & 마스터 로그인)
│   ├── client.html          # 일반 고객용 1:1 대화창
│   ├── master.html          # 마스터 관리자용 상담 콘솔
│   ├── css/style.css        # 스타일시트 (Tailwind + 커스텀)
│   └── js/
│       ├── common.js        # 사운드, 파일포맷, 이미지 라이트박스 등 유틸
│       ├── index.js         # 메인 페이지 로직
│       ├── client.js        # 고객 대화창 실시간 WebSocket 로직
│       └── master.js        # 마스터 콘솔 실시간 제어 로직
├── requirements.txt         # 의존성 패키지 목록
├── run_oz_messenger.bat     # 원클릭 서버 실행기
├── run_public_tunnel.bat    # 무료 퍼블릭 HTTPS 링크 생성기
└── README.md
```
